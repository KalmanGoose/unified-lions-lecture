# 講座課離線語音轉錄、拍照時間軸與重點視覺化戰情室系統

> **專為無網路（No-Internet）教室量身打造的台灣繁體中文業界講座紀錄與重點萃取工具**

本系統解決兩大核心痛點：
1. **無網路教室痛點**：教室沒有 Wi-Fi，傳統依賴雲端 API 的語音辨識與即時筆記工具直接失效。
2. **大海撈針痛點**：兩三小時的演講口語逐字稿動輒兩三萬字，充滿贅字，下課後無論是自己動筆還是餵給 AI 都無從下手。

本系統透過 **「網頁內建原生離線錄音」**、**「前後 90 秒時間窗鎖定」**、**「台灣業界講師語氣詞 Regex 自動高亮」** 以及 **「投影片 × 提煉重點 × 原始語境」三欄對照戰情室**，將上萬字的冗長演講收斂為 15～20 個高純度重點膠囊，課後一鍵同步至 Google 試算表或匯出 Markdown 精華包！

## 🎙️ 在哪裡錄音？技術上如何從錄音變成文字？

### 1. 在哪裡錄音？
打開 [`lecture_highlight_dashboard.html`](file:///Users/ethanchen/Desktop/企業家講座/lecture_highlight_dashboard.html) 頂部橫幅右側，即可看到專屬的 **「🎙️ 課堂全程錄音中心」**：
- 點選 **「🔴 開始課堂全程錄音」**：網頁會直接啟動筆電麥克風，無網路環境下也能收音！
- 畫面具備 **即時音量感應動態條（VU Meter）**，講者說話時條狀圖會隨音量跳動，確保收音正常。
- 講座結束時點擊 **「⏹️ 結束錄音」**，下方會立刻出現播放器可現場試聽，並可隨時點擊 **「📥 下載音檔 (.wav)」** 存檔備份。

---

### 2. 技術上：如何從「錄音聲音」變成「繁體中文逐字稿」？

在無網路教室中，傳統依賴雲端的語音辨識（例如 Chrome Web Speech API）會因無法連線 Google 雲端伺服器而直接失效報錯。本系統採用 **本地端 Faster-Whisper 神經網路模型**，技術處理管線如下：

```text
講者聲音震動 (聲波)
       │
       ▼ 【第 1 步：瀏覽器本地採樣】
AudioContext 以 16,000Hz 採樣率擷取波形，轉為 16-bit PCM WAV 音訊
       │
       ▼ 【第 2 步：聲學特徵轉化】
Faster-Whisper 將音訊切為 30 秒片段，轉換為 80 頻道的「梅爾頻譜圖 (Log-Mel Spectrogram)」
       │
       ▼ 【第 3 步：Transformer 離線解碼 ＋ 台灣繁中 Prompt 提示導引】
神經網路 Transformer 逐字解碼，注入提示詞：
"以下是台灣業界講師的繁體中文商業講座，包含商業實務、架構設計與踩坑案例。"
強制輸出道地台灣正體繁中與標點符號，徹底杜絕簡體字與對岸用語！
       │
       ▼ 【第 4 步：語氣詞正則標記 ＋ 時間窗鎖定】
正則表達式快速過濾「重點是、關鍵在於、踩過的坑、看這張圖」，
自動標黃底並精準綁定到您拍照當下的「前後 45 秒」投影片對照卡片！
```

## 🚀 完整使用流程：三階段作業指南

### 階段一：課前準備（在家或有網路處）

1. **安裝 Python 語音辨識依賴套件**：
   ```bash
   pip3 install -r requirements.txt
   ```
2. **（選配）啟動本地端 Ollama（若想離線提煉列點摘要）**：
   如果您的筆電裝有 Ollama，可下載繁中表現優異的模型：
   ```bash
   ollama run qwen2.5:7b
   ```

---

### 階段二：課堂進行中（無網路教室環境）

1. **開啟系統（兩種方式擇一）**：
   - **方式 A（最推薦）**：在終端機執行 `python3 offline_transcriber.py`，會自動啟動本地伺服器並彈出網頁，此模式下錄完音**點一個按鈕就能直接轉文字**！
   - **方式 B（零指令列）**：直接雙擊開啟 `lecture_highlight_dashboard.html`，純瀏覽器原生運行。
2. **開始錄音**：
   - 點擊右上角 **「🔴 開始課堂全程錄音」**，確認音量動態條正常跳動。
3. **現場隨時拍照或上傳照片**：
   - **筆電鏡頭抓拍**：點擊左側「開鏡頭」啟動筆電攝影機，投影片換頁時點擊「📸 拍下投影片」，系統自動壓縮至 150KB～250KB。
   - **手機拍照轉傳**：亦可將手機拍的照片拖曳進網頁左側上傳區。
4. **隨手打點與記錄**：
   - 點選標籤（如：`🎯 核心結論`、`📊 產業案例`、`🌟 講者金句`、`⚠️ 踩坑經驗`）。
   - 在輸入框快速打下一兩句關鍵數字或洞察，按下 `Command + Enter`。
   - **系統自動在 IndexedDB 中寫入卡片，並為此時間點預先劃定 `[T-45s ~ T+45s]` 的時間窗**。

---

### 階段三：下課後（語音轉文字、雲端同步與心得產出）

1. **一秒將錄音轉為文字**：
   - 若您是用 `python3 offline_transcriber.py` 開啟網頁：
     在錄音中心點擊 **「⚡ 傳送至本地 Whisper 轉為繁中逐字稿」**，系統將自動於本機離線解碼，並把逐字稿自動填入三欄對照卡！
   - 若您是下課後手動轉檔：
     在錄音中心點選「📥 下載音檔 (.wav)」，接著於終端機執行：
     ```bash
     python3 offline_transcriber.py --audio 您的音檔.wav --model large-v3-turbo
     ```
     轉錄產生的 `lecture_transcript.json` 可直接在網頁點選「📂 匯入已轉好逐字稿」載入。

2. **重點戰情室檢索與匯出高純度 Markdown**：
   - 在「乾貨熱區時間軸」上查看整場講座的高頻重點波峰。
   - 勾選最關鍵的 5～8 張對照卡，點擊右上角「📋 匯出精華素材包 (.md)」。
   - 複製生成的結構化 Markdown，貼進 Claude / ChatGPT / Gemini 即可直接生成 1500 字深度講座心得！

3. **一鍵同步至 Google 試算表**：
   - 點擊「☁️ 雲端同步 (Google Sheets)」。
   - 貼上您的 Google Apps Script Web App 網址，點選「開始同步」。
   - 筆記資料將寫入試算表，Base64 投影片照片會自動上傳至 Google Drive 並於儲存格中呈現 `=IMAGE()` 預覽圖！

## 🛠️ Google Apps Script (GAS) 後端部署 5 步驟

1. 開啟 [Google 雲端硬碟](https://drive.google.com/)，建立一份新的 Google 試算表（例如命名為：`企業家講座_重點筆記戰情室`）。
2. 在試算表上方功能表點擊 **「擴充功能」** ➔ **「Apps Script」**。
3. 清空編輯區原有的程式碼，將專案中的 [`Code.gs`](file:///Users/ethanchen/Desktop/企業家講座/Code.gs) 內容完整複製貼入。
4. 點擊右上角藍色按鈕 **「部署」** ➔ **「新部署作業」**：
   - **選取類型**：點擊齒輪圖示，選擇 **「網頁應用程式 (Web app)」**。
   - **說明**：`講座筆記同步 Webhook`
   - **執行身分**：`我 (您的帳號)`
   - **誰可以存取**：**`所有人 (Anyone)`** *(⚠️ 極度重要！)*。
5. 點擊「部署」，依提示授權權限。完成後複製產生的 **「網頁應用程式網址」** 貼至前端 HTML 的雲端同步視窗即可！
